# HealthLens Project Spec — Stage 1M

Stage 1M is the clean professional atlas baseline.

## Locked decisions
- No fake 3D unless it genuinely improves quality.
- User-facing UI must not include development notes.
- Default view is a normal body.
- Layers are selected after default body.
- Atlas Studio is educational and not blurred.
- AR/camera/user-uploaded material uses SafeBlur.
- Selection must update the whole app context.
- Symptom flow must output triage and indicative differential.

## Next stage
Use licensed high-quality 3D anatomical assets or keep professional image-based atlas until assets are available.
