# Project Spec — Stage 1N Baseline

## Locked baseline
- White professional app shell remains the design direction.
- Atlas images are educational references and not blurred.
- Real-user photos, AR captures and uploads remain privacy sensitive and should use SafeBlur.
- The atlas must support a default whole-body view plus multiple harmonized anatomical layers.
- Layer switching must be simple and obvious.
- Clicking/tapping structures must be easy on desktop and mobile.
- Overlay information should appear without awkward navigation.
- Selection should update the symptom flow and educational content.

## Stage 1N delivery
- Harmonized anatomical image stack from user-supplied reference set.
- Direct hotspot interactions.
- Professional detail cards.
- Indicative symptom analysis.
- Knowledge modules and quiz.

## Next logical evolution
- Add true female-specific atlas image parity.
- Add posterior view.
- Add localized front/back pain maps.
- Add camera-based skin review workflow with privacy guardrails.
- Add multilingual medical glossary at scale.
