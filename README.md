# HealthLens Stage 1Q — Multilingual Static Atlas

## Main upgrades
- 21-language interface selector (Dutch + 20 languages).
- Disclaimer gate before app use.
- Static, centered atlas images: no movement/pan/zoom.
- No visible blue selection circles.
- Layer-specific invisible selection regions that highlight when selected.
- Selection works for organs, regions, muscle layer, skeleton layer and other layers.
- Profile influences visual presentation using body-type mode, child/teen modesty overlay and background/skin tone tint.
- Pain score replaces manual mild/severe judgement.
- Professional indicative analysis with red flags, urgency, differential and advice direction.
