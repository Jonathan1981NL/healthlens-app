# Changelog

## v2.0 — Stage 2 release

### Added
- Four-view rotator (front, back, left, right) with smooth transitions.
- Rich medical database (25+ organs) with structured Dutch content.
- Contextual urgency scoring including profile awareness (age).
- AR posture check using MediaPipe Pose (local only, no upload).
- Segmented AR layer switcher (skeleton, muscles, organs).
- Snapshot download for AR view (local PNG, no upload).
- Full Privacy panel with per-key storage listing, JSON export and wipe.
- 21-language dictionary (Dutch + English full; other languages cover key UI strings).
- Dark theme toggle.
- Installable PWA with offline shell service worker.
- Print stylesheet for the analysis output.

### Improved
- Detail panel with 7 tabs and follow-up questions per organ.
- Translucent teal highlight for selection (no circles).
- Modal system for educational content.
- Accessible focus states, keyboard-friendly navigation.
- Mobile layout for all panels.

### Removed
- Any use of visible blue selection circles.
- Any cloud upload or third-party analytics.
